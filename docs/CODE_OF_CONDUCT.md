# Code of conduct

Be respectful, constructive, and specific. Harassment, discrimination, threats, doxxing, and publication of private mailbox or credential data are not acceptable.

Project discussions should focus on reproducible technical behavior and safe collaboration. Maintainers may edit, hide, or remove content that exposes secrets, personal data, internal infrastructure, or unsafe instructions, and may restrict participation when necessary.

For conduct concerns, contact the maintainers privately rather than escalating through a public technical issue.
